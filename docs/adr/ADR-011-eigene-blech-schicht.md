# ADR-011: Eigene Blech-Schicht

- Status: zurückgestellt (nach der Beta)
- Datum: 2026-10-16
- Entscheider: Kernteam

## Kontext

build123d bietet keine Blech-Funktionen.

## Entscheidung

Blech-API auf build123d mit Basislasche, Biegungen, Freischnitten, Biegetabellen (K-Faktor) und Abwicklung als DXF.

## Alternativen

Blech nur als Volumenkörper.

## Konsequenzen

Großes technisches Risiko (R-02); vor einer Umsetzung per Spike abzusichern.
