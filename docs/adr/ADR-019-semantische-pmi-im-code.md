# ADR-019: Semantische PMI im Code

- Status: vorgeschlagen
- Datum: 2026-10-16
- Entscheider: Kernteam
- Geändert durch: ADR-028

## Kontext

Maße und Toleranzen müssen modellgebunden, prüfbar und exportierbar sein.

## Entscheidung

Maße, Toleranzen, Bezüge und Oberflächenangaben sind Objekte im Bauteilmodul, gebunden an Element-IDs; geprüft, in STEP AP242 semantisch exportiert und auf Zeichnungen dargestellt.

## Alternativen

Annotationen nur auf Zeichnungen.

## Konsequenzen

Umfang semantischer PMI im OCCT-Export ist zu prüfen (R-11).
