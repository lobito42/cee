# Sicherheit

Bitte melde Sicherheitslücken **nicht** öffentlich als Issue, sondern über
„Report a vulnerability“ (GitHub Security Advisories) in diesem Repository.

- Wir bestätigen den Eingang innerhalb von 7 Tagen und nennen einen Zeitplan für die Behebung.
- Besonders wichtig sind: Ausführung fremden Codes (Script-Elemente, Plugins, Projekt-Vertrauen nach ADR-045),
  Rechte und Anmeldung (ADR-055), Datenschutz (ADR-056) sowie der Datenfluss zu KI-Anbietern (ADR-037).
- Unterstützt wird jeweils die neueste veröffentlichte Version.
