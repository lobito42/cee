# sdk

Schnittstellen für Plugins, Skripte und Anbindungen. Lizenz: **Apache-2.0** (siehe `LICENSE`), damit
Plugins unter jeder Lizenz entstehen können (ADR-034).

- `python/` – Python-SDK (PyO3-Anbindung an `crates/graph`, Script-Elemente)
- `typescript/` – Plugin-SDK für den Client (eigene Elementtypen, Knoten, Panels)
